# Tarea 1 — Semana 9

Predicción de notas con regresión lineal

Reporte.ipynb contiene el reporte completo con salidas ejecutadas.

## Ejecutar
Recomendado: Python 3.12. Crear entorno con python -m venv .venv y activarlo (Windows: .venv\Scripts\activate). Instalar con python -m pip install -r requirements.txt y abrir con jupyter lab Reporte.ipynb. Alternativamente, subir el cuaderno a Google Colab. Ejecutar todas las celdas en orden.

El código genera los datos sin descargas. proyecto.py permite ejecutar el mismo proyecto desde terminal. resultados/ contiene gráficos, métricas y exportaciones. Los datos son ficticios; consultar los límites en el cuaderno. La tarea 3 guarda modelo.keras y su escalador.
